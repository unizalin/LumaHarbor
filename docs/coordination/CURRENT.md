3. **Aspect-ratio picker records intent but doesn't enforce it** (`Sources/AdjustmentUI/GeometryAdjustmentPanel.swift`, `Sources/LumaHarborApp/Views/CropOverlayView.swift`) — choosing Freeform/Original/Square in `GeometryAdjustmentPanel` only sets `PhotoAdjustments.geometry.cropAspectRatio`; `CropDragMath`/`CropOverlayView` never read it, so dragging a handle is always freeform regardless of the picker's selection.
